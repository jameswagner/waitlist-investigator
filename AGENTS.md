# Agent instructions

- Work on feature branches and open PRs targeting `main`.
- Never merge without explicit human authorization for the current PR revision; default to leaving merging to the human.
- Never self-approve, enable auto-merge, or bypass protections.
- PR descriptions: concise — purpose, validation, limitations.
- Comments: very concise. Explain only non-obvious intent or constraints; don't narrate code.
- Keep README and other docs concise. No redundant docs, generated planning reports, or running progress logs.
- Synthetic data only. Never commit secrets, local databases, or generated artifacts.
- Prefer simple implementations; avoid unnecessary infrastructure.
